# Golf Stats Dashboard

Personal golf dashboard for Tangent/ParGolfShots CSV exports.

## Features
- Upload one or multiple CSV files
- Stores data locally in your browser
- Score trend, driving distance, club gapping, hole scoring, FIR/GIR/putting and dispersion charts
- Mobile friendly
- GitHub Pages ready

## Deploy with GitHub Pages
1. Upload `index.html`, `css/styles.css`, `js/app.js`, and this `README.md` to your repo root.
2. Go to repo Settings > Pages.
3. Source: Deploy from a branch.
4. Branch: main, folder: /root.
5. Save.

## Privacy
Round data is stored in your browser Local Storage. It is not uploaded to GitHub unless you manually commit CSV files.
